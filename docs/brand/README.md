# Recursos de marca

- [Avatar cuadrado](techstore-avatar.png): exportación para redes; símbolo blanco y nodo coral sobre fondo oscuro.
- [Logotipo de la interfaz](../../frontend/src/components/layout/LogoMark.jsx): T con nodo tecnológico, reutilizada en cabecera, pie y animación de entrada.
- [Favicon](../../frontend/public/favicon.svg): versión vectorial para la pestaña del navegador.

El componente toma los colores del tema; el PNG es una exportación fija. Al cambiar la
geometría, revisar las tres versiones, su lectura a 16 px, fondos oscuros y recorte circular.
Consultar el [sistema de diseño](../../DESIGN-SYSTEM.md) antes de regenerar recursos.
